### Задание 1. Подготовить Helm-чарт для приложения

1. Необходимо упаковать приложение в чарт для деплоя в разные окружения. 
2. Каждый компонент приложения деплоится отдельным deployment’ом или statefulset’ом.
3. В переменных чарта измените образ приложения для изменения версии.

> Проверим версию Helm
```bash
microk8s helm3 version
version.BuildInfo{Version:"v3.19.2", GitCommit:"8766e718a0119851f10ddbe4577593a45fadf544", GitTreeState:"clean", GoVersion:"go1.24.13"}
```
> Создадим основу для чарта и проверим создание
```bash
microk8s helm3 create myapp
Creating myapp
```
<img width="590" height="141" alt="image" src="https://github.com/user-attachments/assets/0c323139-b10b-41b8-bee0-3e0cf708d488" /> <br>

> Уберем лишние для данного задания шаблоны, оставляя
> - _helpers.tpl
> - deployment.yaml
> - service.yaml
```bash
rm -f myapp/templates/ingress.yaml
rm -f myapp/templates/httproute.yaml
rm -f myapp/templates/hpa.yaml
rm -f myapp/templates/serviceaccount.yaml
rm -f myapp/templates/NOTES.txt
```
> Добавляем в values.yaml tag с версией для nginx
```yaml
image:
  repository: nginx
  # This sets the pull policy for images.
  pullPolicy: IfNotPresent
  # Overrides the image tag whose default is the chart appVersion.
  tag: "1.27"
```
> Изменяем содержимое deployment.yaml на 
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: {{ .Release.Name }}
  labels:
    app: {{ .Release.Name }}
spec:
  replicas: {{ .Values.replicaCount }}
  selector:
    matchLabels:
      app: {{ .Release.Name }}
  template:
    metadata:
      labels:
        app: {{ .Release.Name }}
    spec:
      containers:
        - name: nginx
          image: "{{ .Values.image.repository }}:{{ .Values.image.tag }}"
          ports:
            - containerPort: 80
```

> Изменяем сожержимое service.yaml на:
```yaml
apiVersion: v1
kind: Service
metadata:
  name: {{ .Release.Name }}
spec:
  type: {{ .Values.service.type }}
  selector:
    app: {{ .Release.Name }}
  ports:
    - port: {{ .Values.service.port }}
      targetPort: 80
```

> Проверим  корректность шаблона до установки
```bash
microk8s helm3 lint ./myapp
==> Linting ./myapp
[INFO] Chart.yaml: icon is recommended

1 chart(s) linted, 0 chart(s) failed

microk8s helm3 template test ./myapp
```
> Увидим желаемые строчки
```bash
name: test
image: "nginx:1.27"
```
