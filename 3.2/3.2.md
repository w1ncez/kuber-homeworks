# Домашнее задание к занятию «Установка Kubernetes» - Винцентини С.Г.


-----

### Задание 1. Установить кластер k8s с 1 master node

1. Подготовка работы кластера из 5 нод: 1 мастер и 4 рабочие ноды.
2. В качестве CRI — containerd.
3. Запуск etcd производить на мастере.
4. Способ установки выбрать самостоятельно.

-----

Спроектируем будущее развертывание. <br>
5 VM - 1 control plane и 4 workers:
- минимум 2 CPU
- минимум 2 GB RAM (4 для control plane)
- уникальный hostname
- статический IP
- сетевой доступ между всеми VM

К сожалению, на момент выполнения задания в инфраструктуре Yandex Cloud создание новых ВМ было ограничено, пришлось использовать локальный VirtualBox.
